Three-panel thumbnail classifier benchmark

Run locally with python -m http.server 8765 in the repository root, then visit http://localhost:8765/scripts/benchmark-thumbnails.html. Extract thumbs.7z and select the common parent folder containing shorts/ and normal/. All decoding/classification happens in your browser; no images are uploaded or sent to Google.
